# swastikkkkk.github.io

My portfolio, live at **[swastikkkkk.github.io](https://swastikkkkk.github.io)**. One vertical page: work, experience, wins and contact.

Built with React, Vite and GSAP. Every project, role and link lives in `src/data.js`, so updating the site means editing one file.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

## Deploy

Pushing to `main` runs `.github/workflows/pages.yml`, which builds the site and publishes it to GitHub Pages.
